# PARALLELY — Collaborative Whiteboard, all-Java edition

Real-time collaborative whiteboard with a Windows-95 retro desktop UI, virtual bot
swarms, an LMAX Disruptor matching-engine visualizer, MCQ consensus polls, and a
Java 21 architecture viewer — built by **the null pointers** (Naga Nikitha Sanaka,
Vanshika Chand, Agastya Pandey, Sai Aswitha, Khalid Raza), SRM University AP,
CSE 213 Advanced Java Programming, 2026–27.

This repo is the **all-Java rewrite** of the original TypeScript/React + Java
project. All application logic — server *and* browser client — is written in Java.
The client is compiled to JavaScript by [TeaVM](https://teavm.org); the only
non-Java source is the frozen HTML/CSS shell that preserves the original look
byte-for-byte. The original repo and its deployment remain untouched as a backup.

## Quick demo (start here)

One command starts everything. JDK 21 is the only requirement.

```bash
./start-demo.sh        # Git Bash: starts both servers, Ctrl-C stops both
```

On Windows you can instead double-click **`start-demo.cmd`**. Then open
**http://localhost:3000**. The launcher starts the Java WebSocket server on
8090 and `jwebserver` on 3000, waits for HTTP, and prints a banner with the URL
and the two-terminal alternative.

- **`DEMO_GUIDE.md`** — scripted 5-minute walkthrough for a reviewer.
- **`VERIFICATION.md`** — build, test, parity and source-census evidence.

`web/app.js` is committed (TeaVM output), so the demo runs with **NO build at
all** — only JDK 21 is needed. The frozen `web/index.html` + `web/app.css`
shell and the pre-compiled browser client are served as-is; no Node, TypeScript
or Maven step is required. If `server/target/apex-engine.jar` is missing,
`start-demo.sh` rebuilds it automatically with the bundled Maven wrapper
(`./mvnw -q package`). For manual control, see **Run (two terminals)** below;
note that this JDK's `jwebserver` requires an absolute `-d` path, which the
launcher supplies automatically.

## Architecture

```
Browser (Win95 shell: web/index.html + web/app.css, frozen from the original)
  └─ web/app.js  ← generated by TeaVM from client/ Java sources
        │  WebSocket  ws://<host>:8090/ws/whiteboard
        ▼
server/  Java 21 + Netty 4.1 — rooms, snapshots, cursor relay, quiz votes
  └─ com.apex.whiteboard.WhiteboardServer   (unchanged from the original)
  └─ com.apex.engine.*                      Disruptor matching engine, WAL, UDP replication
  └─ com.apex.simulator.LoomSimulationMain  10,000 virtual-thread order simulation
  └─ com.apex.benchmark.JmhDisruptorBenchmark  JMH throughput benchmark
```

- `server/` — the original Java backend, copied verbatim (13 sources + tests).
- `client/` — the browser app in pure Java: shell (`AppShell`, `Header`, dialogs,
  taskbar, Start menu), whiteboard studio (canvas tools, bots, live sync), MCQ
  consensus, matching-engine studio, Java 21 viewer. DOM/canvas/WebSocket access
  goes through TeaVM JSO (`client/.../js/`, `shell/Ui.java`).
- `web/` — static shell. `app.css` is the frozen production CSS of the original
  app; `app.js` is the TeaVM build output (committed so the demo runs without a
  build).

## Prerequisites

- JDK 21 (`java`/`javac` on PATH) — the only toolchain you need.
- Maven is **not** required to be installed: use the wrapper scripts, or any
  Maven 3.9+. (On this project's Windows machine, `tools/mvn.sh` in the parent
  workspace launches a downloaded Maven directly because Git Bash breaks the
  stock `mvn` script.)

## Build

```bash
./mvnw -q package        # or: mvn -q package
```

Builds `server/target/apex-engine.jar` (fat jar), runs all JUnit tests (server +
ported client logic tests), and compiles the client to `web/app.js`.

## Run (two terminals)

```bash
# 1. Java WebSocket server on :8090
java -cp server/target/apex-engine.jar com.apex.whiteboard.WhiteboardServer 8090

# 2. Static shell on :3000 — served by the JDK's own web server, no Node needed
jwebserver -p 3000 -d web -b 0.0.0.0
```

Open http://localhost:3000. **Go Live** connects to `ws://<host>:8090/ws/whiteboard`;
open a second browser tab to see drawing and cursors sync through the Java server.

> Git Bash on Windows: prefix java commands with `MSYS2_ARG_CONV_EXCL="*"` when
> passing Windows classpaths so they are not path-mangled.

## WebSocket protocol (JSON)

| type | payload | direction |
|---|---|---|
| `join` | `{room, user, color}` | client → server (server replies with room snapshot) |
| `element` | `{action: 'upsert'\|'delete', room, element}` | both |
| `clear` | `{room}` | both |
| `cursor` | `{user, x, y}` | both |
| `leave` | `{room}` | client → server |
| `question` / `poll` | quiz state | relayed |
| `vote` / `tally` | `{option}` / aggregated counts | client → server / server → clients |
